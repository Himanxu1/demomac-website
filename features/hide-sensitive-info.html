How it works

  1. Record as normal. No need to prepare fake data first, though it never hurts.
  2. Run the scan. ScreenToast reads the text on screen through the whole recording, on your Mac.
  3. Review the list. Every match is shown; keep or remove each cover.
  4. Choose the look: a blur, or a solid mask that blends in.

Covers follow the text as it moves, so a key that scrolls up a terminal stays hidden the whole way.

Manual blur, too

For anything else, like a notification or a face in a thumbnail, drag a blur box onto the preview, resize it, and set the strength from a light frost to completely unreadable. Blurs are anchored to the recording, so when a zoom moves the picture the blur goes with it.

If a live API key was visible, even briefly, the safe move is still to rotate it. Hiding it in the video protects viewers from seeing it; it doesn't un-leak a key you've already shared.
