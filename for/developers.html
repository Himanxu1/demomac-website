What developers use it for

  • GIFs for pull requests and READMEs: export a looping GIF and copy it straight to the clipboard.
  • Bug repros that show exactly what you clicked.
  • Dev-tool and API demos for launch posts and docs.
  • Terminal and editor walkthroughs with zooms so code is readable.

Why ScreenToast fits

  • Secrets hidden automatically. It finds API keys, tokens, private keys and emails in the recording and covers them. Add your own words or regex patterns.
  • Readable code. Zooms on your clicks, and a Glass Loupe that magnifies just a lens around the cursor.
  • Typing at 3× with one command, so long terminal sessions don't drag.
  • Native and local. Built with Apple's own frameworks, records with ScreenCaptureKit, exports with the Mac's video hardware, and never uploads anything.
  • Developer caption style for technical demos.
